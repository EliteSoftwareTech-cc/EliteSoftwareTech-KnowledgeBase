# Frutiger Aero & Classic Windows Engineering

Across `TheShadyRainbow4` and `EliteSoftwareTech-cc`, our core tools target classic Windows customization and native performance:

- **PidgeWin32 (`pidgewin32.elitesoftwaretech.cc`):** A heavily redesigned fork of Windhawk focused specifically on **Windows 10 and older** (excluding Windows 11 mods), introducing `.pw32.cpp` host-brokered dialogs and registry watchdogs while maintaining `.wh.cpp` compatibility.
- **WinNTMU & Vista Packs (`winntmu.elitesoftwaretech.cc`):** Automated reverse-pack backups, ZIP drag-and-drop, UIPI bypass, and 8 curated packs including ClassicUAC, VistaPremier Branding, Vista Help, Games Explorer, WMP 11, and DVD Maker.
- **Native Win32 Build Chain (`elitesoftware-build-automations.elitesoftwaretech.cc`):** Eliminating slow per-repo batch scripts with native C++ CLI binaries (`EliteBuild.exe`, `EliteEasySigner.exe`, `EliteIconReplacer.exe`, `EliteSmartRegsvr.exe`).
